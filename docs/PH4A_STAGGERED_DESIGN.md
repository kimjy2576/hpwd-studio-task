# PH4-A 설계문서 — HX 보존형 staggered FV 정식화 (2026-08-02)

브랜치: feat/ph4a-staggered (분기점 73a7b24 = generality-v1-2026-08-02)
지위: 차기 세션 본공사의 도면. 본 문서의 D-결정을 승인한 뒤 코드에 들어간다.

## 1. 목적과 배경

현행 Evap/Cond_On_Dyn 은 "저장일관 엔탈피형"이다 — 출구 유량이 저장항을
일괄 흡수하므로 연속시간 총질량은 닫히지만, 다음 세 가지가 근사로 남는다.

1. 에너지식에서 V·dp/dt 압력일 항 생략 (콜드스타트류 급압력 과도에서 장부 누락)
2. 셀별 질량 분포 부재 — 저장이 출구에 몰려 HX 내부 충전 이동의 시공간이 뭉개짐
3. 면(face) 유량 미지수 부재 — 셀간 유량이 단일 m_ref_col

표준(ThermoPower Flow1D, Modelica.Fluid, TIL 계보)은 셀 보존식 + 면 유량의
staggered FV 다. 본 작업은 그 표준형을 병행 모델(Evap_On_DynC, Cond_On_DynC,
Cycle_L3C)로 구현한다. 기존 모델·지문은 건드리지 않는다 (백업 3겹:
태그 speed-mode / generality-v1, 동결 브랜치, 측정 아카이브).

세션 실측이 정한 역할 분담과의 관계: 드리프트의 지배항은 적분기 오차
(수치→기호 전환으로 19배 개선 실측)였고, 본 정식화는 남는 구조 오차
(위 1~3)를 제거하며 충전 이동 연구의 기반을 만든다. 통합 시뮬레이터
3모드에서 on-design 티어의 냉매측 정식화가 된다.

## 2. 정식화 명세

기호: 셀 k=1..N (냉매 흐름 방향), 면 k±1/2. 셀 부피 V_k (기하에서),
면 유량 ṁ_{k+1/2}, 상류 엔탈피 h_up.

### 셀 보존식 (연속형)

질량:   d(M_k)/dt = ṁ_{k-1/2} − ṁ_{k+1/2},  M_k = ρ(p_k, h_k)·V_k
에너지: d(U_k)/dt = ṁ_{k-1/2}·h_up,in − ṁ_{k+1/2}·h_up,out + Q_ref,k
        U_k = M_k·h_k − p_k·V_k        (⇒ V·dp/dt 항이 자동 포함된다)

### D1. 압력 분해능 — [권고: 단일 HX 압력 상태 + 준정상 마찰 재구성]

전 셀 p_k = p_hx − Δp_fric(1..k) 로 두고 p_hx 하나만 미분 상태로 승격한다.
근거: 저압강하(수십 kPa)·저마하 HP 조건에서 압력파 동역학은 불필요하며,
상태 수 증가를 +1 로 억제해 초기화 NLS(1198 이력) 취약성을 자극하지 않는다.
Δp_fric 은 기존 HXCorr.msh_2phase 준정상 체인을 면 단위로 재사용한다.
Phase 2 (필요 시): per-cell p_k 승격 — G3 에서 분포 동역학 부족이 실측될 때만.

### D2. 상태 선택 — [권고: Phase 1 = (p_hx, h_k) / Phase 2 = (M_k, h_k)]

Phase 1 (Modelica.Fluid 표준형): 상태 (p_hx, h_1..N).
  질량식은 도구가 EOS 를 전개한다:
    V_k·(∂ρ/∂p·dp_k/dt + ∂ρ/∂h·dh_k/dt) = ṁ_{k-1/2} − ṁ_{k+1/2}
  전개에 필요한 것은 정방향 ρ(p,h) 와 그 도함수뿐 — P 트랙이 이식한
  해석 rho_ph_a / rho_ph_a_d 가 정확히 이 요구 물성이다. rho_ph_a 의
  국소 비단조는 역산에서만 문제이며 정방향 전개에서는 무해하다.
  폐합 성격: 연속시간 셀별 보존 정확, 이산시간은 적분 허용오차 한도
  (기계정밀 아님 — 기호 야코비안 병용 시 밴드 ±0.04%급, P5 실측 준용).

Phase 2 (기계정밀 질량): 상태 (M_1..N, h_1..N), ρ_k = M_k/V_k 는 정의식.
  p_hx 는 스칼라 폐합식 Σ V_k = Σ M_k/ρ(p_k(p_hx), h_k) 의 해 —
  정방향 ρ 만 쓰는 스칼라 뉴턴이지만 ∂ρ/∂p>0 단조가 전제다.
  ⇒ 생성기 과제 "ρ 단조 하드제약 재피팅" 완료가 선행조건. 그 전 착수 금지.

### D3. 면 유량 — [권고: 준정상 마찰 + 상류(upwind) 엔탈피, 관성 옵션 유지]

내부 면: ṁ_{k+1/2} 는 미지수, 면 압력차−마찰 균형(준정상)으로 결정.
경계 면: port_a/b 유량. 상류 엔탈피는 흐름 방향 부호로 선택하되
noEvent+smooth 전환(기존 w_chk 패턴 재사용)으로 이벤트를 만들지 않는다.
use_momentum=true 옵션에서 총 관성 L_inert·dṁ/dt 는 입구 면 하나에만 건다
(현행과 동일한 집중 관성 — 분산 관성은 표준에서도 통상 생략).

### D4. 포트·경계 — 현행 RefPort/stream 유지

port_a.p = p_hx (입구 면 기준), port_b.p = p_hx − Δp_total.
h_outflow 는 말단 셀 상류값. 이웃(볼륨·EEV·Comp)은 무수정 호환이 목표다.

### D5. 공기측·습식 기구 — 불변 재사용

T_w 벽 동역학, w_wet/DTB, b·eta_o·Q_air/Q_lat 체인은 그대로 가져온다.
냉매측 Q_ref,k 결합 지점만 새 셀 인덱스에 배선한다. (PH1 SH_ph, PH2/PH3
규약이 이미 Medium 층에 있으므로 추가 작업 없음.)

### D6. 초기화

(p_hx, h_k) start 값 + steadyInit 옵션은 현행 규약 승계. 콜드스타트
충전 유도(h_rest, M_dis_start 자동화, 2026-07-26 로직)는 Cycle_L3C 에서
재사용한다. 초기화 NLS 는 1198 이력이 있으므로: nominal 을 상태 전원에
명시(p 1e6, h 4e5, M 1e-2)하고, 초기화 실패 시 homotopy 를 켜기 전에
start 값 정합(볼륨-HX 압력 일치)을 먼저 점검한다.

### D7. 검증 사다리 (게이트) — 각 단계 통과 전 다음 단계 착수 금지

G0 밀폐 단품: 포트 캡(ṁ=0) + 공기 가열/냉각 스텝 (40→5→40 °C).
   [2026-08-02 S2 실측으로 판정 분리 — 원안 1e-6 은 Phase 2 몫을 Phase 1 에
    잘못 물린 것이었다]
   G0-P1 ((p,h) 상태): ① tol 스케일링 실증 (1e-6→1e-8 에서 ≥30배 감소)
     ② |drift| < 5e-5 @ (수치 tol 1e-8 또는 기호 tol 1e-6).
     실측: 수치 1e-6 9.07e-4 / 수치 1e-8 2.48e-5 (37배) /
     기호 1e-6 2.78e-5 (같은 tol 33배 이득) — 통과.
     페어링 원칙 실증: on-design 티어 기본 야코비안은 symbolic.
   G0-P2 ((M,h) 상태, Phase 2): |ΔM_tot|/M_tot < 1e-6 기계정밀급.
G1 단품 A/B: DynC vs Dyn, 동일 경계(고정 p_in/h_in/ṁ)에서 준정상 수렴점.
   판정: Q_total·SH·Δp 상대차 < 1% (정식화 차이는 과도에만 있어야 함).
G2 사이클 교체: Cycle_L3C 600s.
   판정: 완주 + 수치 드리프트 ≤ 기준밴드(±0.1%) + symbolic 교차(±0.05%).
   ※ 지문 '동일'이 아니라 '물리 대등' — V·dp/dt 항 포함으로 궤적은
   달라지는 것이 정상이며, 그 차이 자체가 본 작업의 관측 대상이다.
G3 충전 이동: EEV 스텝(75→150pulse)에 대한 셀별 M_k 응답.
   판정: 액 전선(front) 전파의 단조성·시간스케일 물리성 (정성 게이트).

### D8. 성능 예산

상태 증가: h 12 + p_hx 2 (+ 벽 12 기존) — Phase 1 은 +2 상태 수준.
면 유량 미지수 12×2 가 NLS 에 추가되나 삼중대각 구조라 티어링 양호 예상.
목표: 수치 야코비안 600s 가 기준(~217s)의 2배 이내. 초과 시 D1 Phase 2
보류하고 면 유량 준정상 대입(명시적 체인)으로 후퇴한다.

### D9. 작업 순서 (차기 세션)

S1 본 문서 D-결정 승인 확인
S2 Evap_On_DynC 골격(냉매측만, 공기측 스텁) + G0
S3 공기·습식 배선 + G1
S4 Cond_On_DynC (동일 패턴 복제) + G0/G1
S5 Cycle_L3C 조립 + G2 (수치 → symbolic 교차)
S6 G3 + 판정 문서화 → 병합·역할분담 논의 (semi-empirical 티어와 병존)

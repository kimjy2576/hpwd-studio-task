## 2. 정지(콜드스타트 초기) 조건

| 항목 | 현재 모델 | 물리적 값 (100 g, 20 °C) | 상태 |
|---|---|---|---|
| 정지압 `p_rest` | 12.5 bar (**T_sat 36.1 °C**) | **8.365 bar** (20 °C 포화압) | ⚠️ |
| 정지 엔탈피 `h_rest` | 575 kJ/kg (**x = 0.886**) | **265.5 kJ/kg** (x = 0.040) | ⚠️ |
| 상태 | 거의 **증기** | 거의 **액** | ⚠️ |
| 초기화 방식 | `fixedState=true` (p,h 직접 지정) | 충전량 → ρ = M/V → p(ρ,T_amb) | ⚠️ |

> **정지압은 어큐 체적과 무관** — 2상이라 포화압으로 고정. 어큐 200 cc 확정 기준
> 총 414.1 cc, ρ = 241.5 kg/m³, x = 0.040, h = 265.5 kJ/kg (hl 251.6 / hv 595.9).

### 이 오류가 유발한 증상 (실측)
- `Q_evap` **음수** (−427 W): 냉매 36 °C > 공기 20 °C → 증발기가 열을 버림
- `evap.x_out` 이 **1.0 에 고착**: 정지 상태가 이미 증기라 증발시킬 액이 없음
- 콜드스타트 t≈57 s 정지 (고정개도) / t≈17 s (PI)

## 9. 우선 조치 순서 (제안)

1. **정지조건 물리화** — `p_rest` **8.365 bar**, `h_rest` **265.5 kJ/kg**, `T_w_start` 20 °C
2. **체적 노드 실체적화** — vol1 18.3 / vol2 3.7 / vol3 3.7 / vol4 **218.3**(배관 18.3 + 어큐 200) cc
3. **`L_path` 버그 수정** — 응축기 `Nr·Nseg·L_seg` → `M·L_seg` (Ncol 누락, dp 1/4 과소)
4. **리턴밴드 반영** — 경로·내용적 +6.6 %
5. **응축기 FPI 22 → 20**
6. **EEV 최소개도 3 % → 6 %** (30/500 스텝)
7. 위 반영 후 콜드스타트 재시도 → 안정되면 드럼 연결(커플드)로 확장

## 10. 확인 요청 항목 (❓)

- EEV 최대 스트로크 실물값 (500 스텝에 대응하는 mm)
- 실제 압축기 기동 시퀀스 (현재 램프는 임의값)
- `rho_ref_nom` (셀 홀드업 산정용 공칭밀도) 적정값
- **`L_path` 수정 시 dp 가 0.155 → 약 0.62 bar 로 증가** — 실측 추정 0.1~0.2 bar 범위를
  넘어서므로, 상관식 과대평가인지 실측 재확인이 필요한지 판단 필요

### 확정된 값 (2026-07-24)
- 냉매 충전량 **100 g**, 어큐뮬레이터 **200 cc**
- 배관 1/4" 동관: 압축기→응축기 1.0 m / 응축기→EEV 0.2 m / EEV→증발기 0.2 m / 증발기→압축기 1.0 m
- EEV 시트경 1.0 mm, 500 스텝, 최소 30 스텝
- 팬 풍량 고정 (가변 아님)
- 리턴밴드 `L_path` 에 **포함**
- 응축기 FPI **20**

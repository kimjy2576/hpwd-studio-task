## 압축기 기동 로직

```
1단계  0 → 최소(30 Hz)          2 rps/s
2단계  최소 도달 시             1 rps/s 로 전환
3단계  중간 1(55 Hz) 도달 시    1분 이상 유지
4단계  유지 후                  1 rps/s 재상승
5단계  중간 2 도달 시           1분 이상 유지   (현재 미사용)
6단계  유지 후                  1 rps/s 재상승
```

### 최우선 규칙 — 35 Hz 강제 유지

> 압축기는 **설정 Hz와 무관하게** 기동 시 **35 Hz 도달하면 무조건 2분 유지**한 뒤
> 목표 Hz로 제어를 시작한다.

이것이 다른 모든 단계보다 앞섭니다. 즉 실제 기동 순서는:

```
0 Hz
 ↓ 2 rps/s
30 Hz (최소)
 ↓ 1 rps/s
35 Hz  ────────── 2분 강제 유지 ──────────
 ↓ 1 rps/s
목표 Hz (55 Hz 경유 시 1분 유지)
```

### 시간축 계산 (목표 60 Hz 기준)

| t [s] | Hz | rpm | 구간 |
|---|---|---|---|
| 0 | 0 | 0 | — |
| 15 | 30 | 1800 | 1단계 종료 (2 rps/s) |
| 20 | 35 | 2100 | 35 Hz 도달 |
| 140 | 35 | 2100 | **2분 유지 종료** |
| 160 | 55 | 3300 | 중간 1 도달 |
| 220 | 55 | 3300 | **1분 유지 종료** |
| 225 | 60 | 3600 | 최대 도달 |

목표가 35 Hz 이하이면 2분 유지 후 바로 목표로 갑니다.

## EEV 제어 로직

### 밸브 사양

| 항목 | 값 | 비고 |
|---|---|---|
| **전체 스트로크** | **450 pulse** | 최대치 |
| 초기 개도 | 450 pulse | **완전 개방에서 시작** |
| 최소 개도 | 75 pulse | 4단계에서 도달 (전체의 16.7 %) |
| 5단계 상한 | 300 pulse | 전체의 66.7 % |
| 정상 제어 속도 | 5 pulse/s | 전 스트로크 통과 90 s |

**초기가 완전 개방**이라는 점이 중요합니다. 기동 시 밸브를 활짝 열어
압력 평형을 돕고, SH 가 잡히기 시작하면 단계적으로 조입니다.

### 단계

```
1단계  초기 개도 450 pulse

2단계  압축기 기동 시점부터 2분 유지
       (압축기 35 Hz 2분 유지와 같은 구간)

3단계  SH ≤ 5 K 가 될 때마다
       10초 주기로 50 pulse 씩 감소

4단계  마지막 100 pulse 구간에서는
       75 pulse 로 감소 (50 씩이 아니라 한 번에)

5단계  75 pulse 도달 시
       SH ≥ 15 K 이면 30초마다 4 pulse 증가
       최대 300 pulse 까지만

6단계  압축기 기동 후 2분 경과 && 5단계에서 SH < 15 K
       → 정상 제어 시작
         속도 5 pulse/s
         목표 SH 4 K
         데드밴드: SH 6 K 도달 시 개도 열기
                   SH 3 K 도달 시 개도 닫기
```

### 개도 궤적 (3~4단계)

```
450 → 400 → 350 → 300 → 250 → 200 → 150 → 100 → 75
      각 단계 10초 주기, SH ≤ 5 K 일 때만 진행
      마지막 100 → 75 는 25 pulse (예외)
```

## 현재 모델과의 차이

| 항목 | 현재 모델 | 실제 |
|---|---|---|
| 기동 램프 | 8.3 rps/s (임의) | 2 rps/s → 1 rps/s |
| 35 Hz 유지 | 없음 | **2분 강제** |
| 55 Hz 유지 | 없음 | 1분 |
| EEV 초기 개도 | 18~24 % (연속값) | 450 pulse |
| EEV 제어 | PI (Kp/Ki) | 단계별 규칙 기반 |
| EEV 목표 SH | 6 K | **4 K** |
| EEV 데드밴드 | ±0.5 K | 3~6 K (비대칭) |
| 최소/최대 개도 | 6 / 100 % | 75 / 300 pulse |

### pulse ↔ % 환산

현재 모델은 `n_max = 500` pulse 를 100 % 로 봅니다. 그러면

전체 스트로크가 450 pulse 이므로

| pulse | % |
|---|---|
| 450 | 100.0 |
| 300 | 66.7 |
| 100 | 22.2 |
| 75 | 16.7 |

현재 모델의 `n_max = 500` 은 **450 으로 고쳐야** 합니다.
`pps_max = 30` 도 실제 정상제어 속도 **5 pulse/s** 와 다릅니다.

## 구현 시 주의

1. **숫자는 전부 파라미터로.** 위 값들은 변경될 수 있습니다.
2. **35 Hz 2분 유지가 최우선.** 다른 단계보다 앞서 적용됩니다.
3. **EEV 3~5단계는 조건부 상태 기계**입니다. 시간 기반 램프가 아니라
   SH 조건을 만족할 때만 진행하므로, Modelica 에서는 `when` 절과
   상태 변수로 구현해야 합니다.
4. **데드밴드가 비대칭**입니다 (목표 4 K, 여는 기준 6 K, 닫는 기준 3 K).
   기존 PI 의 대칭 데드밴드와 다릅니다.
